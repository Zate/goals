# Example project goals

Track independently verifiable outcomes for the project.

## Operating Rules

- Follow queue order and goal prerequisites.
- Preserve unrelated work and commit only with authorization.

## Model And Token Guidance

Use the available model and inspect the context needed for the selected goal.

## Goal File Format

Each goal has a stable ID, status, objective, source, scope, acceptance
criteria and verification. Optional prerequisites reference IDs.

## Execution Loop

Inspect status and reconcile interrupted work. Select an eligible goal, verify
its outcome, record results and update status and queue consistently.

## Definition Of Done

Acceptance criteria and required verification pass. Record checks and results.

## Verification

Use each goal's commands and the project's applicable checks.

## Blocking And Recovery

Record blockers and attempted checks. Reconcile actual work and evidence before
resuming. Preserve changes whose ownership is unclear.
